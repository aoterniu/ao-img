📋 关于 ao 图床

简单、快速、免费的个人图床

基于 Cloudflare R2 对象存储，全球 CDN 加速，零出口流量费用。

支持图片、短视频、ZIP 批量上传。可设置密码保护、格式转换、质量压缩。

开放 RESTful API，兼容 PicGo、Typora 等第三方工具。

技术栈：Cloudflare Worker + R2 存储 + KV 统计 · GitHub 源码
